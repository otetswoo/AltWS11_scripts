# Скрипты

В этой папке находятся полезные скрипты для работы с проектом.

## Использование

1. Клонируйте репозиторий на любую машину:
   ```bash
   git clone <url-репозитория>
   ```

2. Перейдите в папку со скриптами:
   ```bash
   cd scripts
   ```

3. При необходимости сделайте скрипты исполняемыми:
   ```bash
   chmod +x *.sh
   ```

4. Запустите нужный скрипт:
   ```bash
   ./имя_скрипта.sh
   ```
